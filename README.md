# BATTLETECH Türkçe Yerelleştirme — Hy-MT2

Bu depo, BATTLETECH (2018) Almanca yerelleştirme CSV dosyasındaki oyuncuya görünen metinleri Türkçeye çevirmek için ChatGPT tarafından hazırlanan ücretsiz GitHub Actions + Tencent Hy-MT2 işlem hattını barındırır.

Kaynak dosyada `KEY` sütunu değiştirilmez. Çeviri `de-DE` sütununa yazılır ve çıktı `BATTLETECH_strings_tr-TR.csv` adıyla üretilir.
